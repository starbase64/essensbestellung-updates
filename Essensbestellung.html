So funktionieren HTML-Updates

Die Anwendung selbst bleibt eine einzelne lokale HTML-Datei. Beim Start kann sie ein kleines öffentliches Update-Manifest auf GitHub abrufen. Ist dort eine neuere Version eingetragen, erscheint hier ein Download-Button für die neue HTML-Datei.

Die bestehende Datei wird aus Sicherheitsgründen nicht lautlos überschrieben. Nach dem Download ersetzt du lediglich die alte HTML-Datei. Deine gespeicherten Bestelldaten bleiben im Browser erhalten; zusätzlich empfiehlt sich vor einem Update eine Datensicherung.

Neue Version herunterladen

Datenschutz/Sicherheit: Für die HTML-Version wird kein GitHub-Token im Browser gespeichert. Der private Rust-Quellcode kann privat bleiben. Für vollautomatische Versionsprüfung muss lediglich das Update-Manifest öffentlich erreichbar sein.
